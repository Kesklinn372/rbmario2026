# Red Bull Soapbox Race

Это одностраничный сайт для команды Red Bull Soapbox Race.

## Как использовать

1. Поместите свои фотографии в папку `images`.
2. Переименуйте файлы в `photo1.jpg`, `photo2.jpg`, `photo3.jpg`, `photo4.jpg` или обновите пути в `index.html`.
3. Откройте `index.html` в браузере.

## Структура

- `index.html` — главный файл сайта.
- `styles.css` — стили оформления.
- `script.js` — простой скрипт для мобильного меню.
- `images/` — папка для ваших фотографий.
